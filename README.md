# Rescale

A privacy-first image tool that runs **entirely in the browser**. No uploads, no
servers, no tracking — every pixel is processed locally with the Canvas API.

Built with **Next.js 16** (App Router) and TypeScript. The page itself is fully
static: there is no backend, no API route and nothing to deploy beyond files.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
```

| script | does |
|---|---|
| `npm run dev` | dev server with Turbopack |
| `npm run build` | production build |
| `npm start` | serve the production build |
| `npm run lint` | ESLint (`eslint .`) |
| `npm run typecheck` | `tsc --noEmit` |

## Features

Three tools share one workspace (preview, output format, download):

### Resize
- **By dimensions** — width/height in pixels with an aspect-ratio lock.
- **By percent** — slider + input, with 25 / 50 / 75 / 100 / 200 % quick chips.
- **Preset sizes** — screen resolutions, social-media formats, avatars/icons
  (edit `lib/presets.ts` to add your own).
- **Fit modes** when the target proportions differ: **Fit** (letterbox),
  **Fill** (center-crop), **Stretch**.
- **Progressive downscaling** for clean results on large reductions.

### Upscale
- **2× / 3× / 4×** Lanczos-3 separable resampling (`lib/upscale.ts`).
- **Sharpen** — unsharp-mask pass, 0–100.
- **Reduce noise** — optional 3×3 median pre-pass.
- Fully offline, no model download. Large factors run for a few seconds on the
  main thread (a spinner shows); output is capped at 40 MP.

### Cut out (background removal)
- Colour-key matte (`lib/bgremove.ts`): **Auto detect** samples the image
  border, or **Pick from image** to eyedrop the background colour off the canvas.
- **Tolerance** and **Edge softness** sliders.
- **Only remove areas touching the border** — edge-connected flood fill so
  same-coloured regions inside the subject are kept.
- **Despill** — colour decontamination on partial-alpha edge pixels.
- Replace the background with **transparent**, white, black, or a custom colour.
  Transparent output forces an alpha format (PNG/WebP) and disables JPG.
- Best on plain / gradient backgrounds; not an AI segmenter — fine hair and busy
  scenes need manual tuning.

### Shared
- Export as JPG, PNG, or WebP with a quality slider.
- Live preview with on-canvas dimension badges and a real, encoded before/after
  file-size comparison.
- Drag & drop anywhere, paste from clipboard (`Ctrl`/`Cmd`+`V`), copy result to
  clipboard, one sample image generated offline.
- Light / dark theme (follows the OS, with a manual toggle). The saved choice is
  applied by a tiny inline script in `app/layout.tsx`, before first paint, so
  dark-mode users never see a light flash.
- Optional left/right ad rails (`.ad-rail`) that appear at ≥1240px and collapse
  once an image is loaded.

## Project layout

```
app/
  layout.tsx        metadata API, fonts, JSON-LD, theme bootstrap
  page.tsx          server component: header, SEO copy, footer, FAQ
  globals.css       theme tokens + all styling
  robots.ts         generated /robots.txt
  sitemap.ts        generated /sitemap.xml
components/
  ToolApp.tsx       client root: file input, drag & drop, paste, toast
  Dropzone.tsx      empty state
  Stage.tsx         preview, dimension badges, eyedropper, zoom hint
  Panel.tsx         file header, tool tabs, output format, actions
  Readout.tsx       before/after size comparison
  Toast.tsx         transient status line + useToast
  ThemeToggle.tsx   light/dark switch
  Icons.tsx         inline SVGs
  ui/Seg.tsx        segmented control
  panels/           ResizePanel · UpscalePanel · CutoutPanel
hooks/
  useImageTool.ts   all tool state (reducer) + debounced render→encode pipeline
lib/
  types.ts          shared types
  presets.ts        preset size list (data only)
  engine.ts         load / resize / encode          — pure, React-free
  upscale.ts        Lanczos resample + unsharp + median — pure, React-free
  bgremove.ts       colour-key matte + flood fill + despill — pure, React-free
  filename.ts       output filename construction
  site.ts           SEO copy, FAQ, JSON-LD builders
public/
  favicon.svg       icon (also used by the manifest)
  site.webmanifest  PWA metadata
legacy/             the original static HTML/CSS/JS version, for reference
```

The `lib/` modules are deliberately React-free — they take a source image and
options and return a canvas. All UI state lives in `hooks/useImageTool.ts`,
which debounces input by 110 ms, shows the spinner after 170 ms, and discards
results from superseded runs.

`AGENTS.md` / `CLAUDE.md` are generated by `next dev` itself; deleting them only
recreates them on the next run.

## Before you deploy

Set your real domain — it feeds the canonical URL, Open Graph tags, JSON-LD,
`robots.txt` and `sitemap.xml` from one place (`lib/site.ts`):

```bash
# .env.local
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

Then:

| Item | Where | Do this |
|---|---|---|
| `og-cover.png` | referenced by `app/layout.tsx` | add a real **1200×630 PNG/JPG** at `public/og-cover.png` |
| AdSense | `.ad-slot` in `app/page.tsx` | drop in your `<ins class="adsbygoogle">` unit and load the script with `next/script` |

Also recommended for ranking:

- Serve over **HTTPS** with HTTP/2 and brotli. Next sets long `Cache-Control`
  on hashed assets automatically.
- Submit `sitemap.xml` in Google Search Console and Bing Webmaster Tools.
- Run Lighthouse; the ad rails reserve their space, so there is no layout shift.

### Static export

There is no server-side logic, so the app exports to plain files. Uncomment
`output: "export"` in `next.config.ts` and `npm run build` writes `./out`,
deployable to any static host.

## SEO

- Title, description, canonical, robots, Open Graph, Twitter Card, `theme-color`
  and the web manifest all come from the Next **metadata API** in
  `app/layout.tsx`.
- **JSON-LD**: `WebApplication` and `FAQPage`. The FAQ is defined once in
  `lib/site.ts` and rendered into both the visible copy and the structured data,
  so the two cannot drift — which is what Google requires.
- One visible `<h1>` plus an ~700-word indexable article below the tool, all
  server-rendered: it is in the HTML with JavaScript disabled.
- Fonts are self-hosted automatically by `next/font`, so there is no
  third-party request — which is what the "no tracking" claim needs.

## Extending

- **Crop / rotate / flip** — add a transform step before `Engine.render()`.
- **Batch** — loop the per-tool run + `Engine.encode` over a file array and zip
  the blobs (e.g. with JSZip).
- **AI upscale / segmentation** — swap `Upscale.run` / `BgRemove.run` for a
  dynamically imported model while keeping the same call sites.
- **Web Worker** — the `lib/` modules are DOM-light enough to move behind a
  worker with `OffscreenCanvas`, which would unblock the main thread on large
  upscales.

## Browser support

Modern Chrome, Edge, Firefox, and Safari. WebP export depends on the browser's
canvas encoder; if it's missing, Rescale falls back to PNG and tells you.
